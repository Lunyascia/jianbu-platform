# 健步走线上活动系统 — 需求说明

## 1. 项目背景

面向"全县工会会员"开展健步走线上活动。会员通过微信小程序报名并参与活动，每日同步微信运动步数打卡，按步数累计积分形成排名，活动结束后按名次颁发奖励与电子证书；管理员在后台进行组织机构管理、数据统计、异常数据删除与批量作弊账号处理。

## 2. 系统组成（三个端）

| 端口 | 使用者 | 用途 |
|---|---|---|
| 小程序报名页面 | 全县工会会员 | 查看活动信息、提交报名 |
| 微信小程序 | 已报名的会员 | 步数打卡、积分排名、奖励介绍、获奖证书 |
| 后台管理系统 | 系统管理员 / 管理员 | 组织机构管理、数据统计、异常数据删除、批量处理作弊账号 |

### 2.1 小程序报名页面
- 查看当前可报名的活动（名称、封面、时间、规则、积分规则）
- 填写报名表：姓名、手机号、单位、身份证号（可选）
- 提交后系统**自动审核**（字段校验 + 手机号唯一 + 文本内容安全）
- 无异常 → 报名成功进入活动；有异常 → 无法提交并提示修改
- 支持**待提交草稿**：报名未提交前可自行修改

### 2.2 微信小程序（已报名会员）
- 首页：微信步数同步打卡、今日步数/达标进度
- 积分排名：个人积分、排行榜
- 奖励介绍：各名次区间对应奖励
- 获奖证书：电子证书查看/保存

### 2.3 后台管理系统
- 组织机构管理：工会组织机构树（复用 sys_dept）
- 活动管理：活动 CRUD、报名时间窗口、积分规则配置
- 报名管理：审核、取消报名、撤下报名人信息、停用报名账号、调整单位
- 会员管理：会员信息维护、停用
- 数据统计：报名人数、参与率、步数/积分排行统计
- 异常数据删除：批量删除异常步数数据
- 批量处理作弊账号：标记异常、删除数据、停用账号

## 3. 用户角色

| 角色 | 来源 | 权限 |
|---|---|---|
| 系统管理员 | 后台 sys_user | 全部管理功能 |
| 管理员 | 后台 sys_user（可细分） | 活动/报名/会员/统计/作弊处理 |
| 工会会员 | 小程序 openid + 手机号 | 查看活动、报名、打卡、排名、证书 |

## 4. 报名状态机

```
0 待提交草稿（会员可自行修改）
   │  点击"提交"→ 系统自动审核
   │    校验：姓名/手机号/单位非空、手机号格式+唯一、
   │        文本内容安全（敏感词过滤）
   ▼
1 待审核 ──通过──► 2 审核通过（进入活动）
   │                 ★ 通过后：姓名、手机号锁定不可改
   │
   └──未通过──► 退回 0 草稿，提示修改原因

管理员后台操作：
   2 ──取消报名──► 3 已取消
   2 ──撤下信息/停用账号──► 4 已停用（撤下报名信息、停用账号）
   任意状态 ──调整单位──► 更新 dept_id/dept_name（管理员可操作）
```

| 状态码 | 含义 | 说明 |
|---|---|---|
| 0 | 待提交草稿 | 会员可修改，未正式报名 |
| 1 | 待审核 | 已提交，系统自动审核中 |
| 2 | 审核通过 | 报名成功，进入活动，姓名/手机号锁定 |
| 3 | 已取消 | 管理员取消报名 |
| 4 | 已停用 | 管理员撤下报名信息并停用账号 |

## 5. 核心业务规则

### 5.1 步数打卡
- 已报名且审核通过的会员才能打卡
- 步数来源：微信运动（`uni.getWeRunData()` 授权后同步），开发期可用模拟接口
- 每人每天记一条步数记录（会员+活动+日期 唯一）
- 步数在活动日期范围内才有效

### 5.2 积分
- 按"每千步积分"规则计算：`积分 = 当日步数 ÷ 1000 × 每千步积分`
- 积分写入积分流水表，按活动汇总参与排名

### 5.3 异常检测（作弊）
- 单日步数超过阈值（如 > 8 万步）→ 标记异常
- 非活动期间产生的步数 → 标记异常
- 连续异常突增（远超本人历史均值）→ 标记异常
- 管理员可：标记异常 / 删除异常数据 / 停用账号 / 取消报名，全部留痕审计

### 5.4 奖励与证书
- 活动结束后按积分排名生成名次
- 按名次区间匹配奖励档位（walking_award）
- 前若干名生成电子证书（walking_certificate），会员可在小程序查看/保存

## 6. 页面设计参考

- 页面布局与用色参考"**藤县工会活动**"小程序（非像素级复刻）
- 要点：活动主视觉 banner + 卡片式功能入口 + 统一主色系（工会红/健康绿系）
- 小程序端典型页面流：
  ```
  活动列表页 → 活动详情页(报名) → 报名成功/失败提示
           → 首页(步数打卡 + 排名 + 奖励 + 证书)
           → 个人中心(我的报名/证书/积分)
  ```

## 7. 技术栈

- 后端：Spring Boot 3.x（RuoYi-Vue-Plus 5.6.0），MyBatis-Plus，Sa-Token
- 数据库：MySQL 8（ry-vue 库，walking_* 前缀表）
- 缓存：Redis
- 小程序端：uni-app（Vue3），H5 报名页 + 微信小程序
- 后台管理：plus-ui（Vue3 + Element Plus）
