# 健步走线上活动系统 — 数据库设计

- 目标库：`ry-vue`（RuoYi-Vue-Plus 主库，UTF8MB4）
- 业务表前缀：`walking_`
- 建表脚本：`sql/walking_tables.sql`
- 约定：主键 `id` bigint（应用雪花 ID，非自增）；逻辑删除 `del_flag`；审计字段 `create_dept/create_by/create_time/update_by/update_time`；多租户 `tenant_id`（默认 `000000`）

## 1. ER 关系总览

```
sys_dept（复用：工会组织机构树）
   │ 1:N
walking_member（会员） ──1:N── walking_registration（报名） N:1── walking_activity（活动）
    │                                                              │ 1:N
    │ 1:N                                                          ├─ walking_step_record（步数）
    ├─ walking_step_record ─────────────────────────────────────► ┤
    ├─ walking_points（积分）─────────────────────────────────────► ├─ walking_points
    ├─ walking_certificate（证书）───────────────────────────────► └─ walking_award（奖励档位）
    └─ walking_cheat_log（作弊处理审计）

walking_registration ──1:N── walking_audit_log（审核日志）
```

## 2. 表清单

| 表名 | 说明 | 关键约束 |
|---|---|---|
| walking_activity | 活动 | 状态索引、日期索引 |
| walking_member | 会员 | openid 唯一、phone 唯一 |
| walking_registration | 报名 | (member_id, activity_id) 唯一 |
| walking_step_record | 步数打卡 | (member_id, activity_id, record_date) 唯一 |
| walking_points | 积分流水 | (member_id, activity_id) 索引 |
| walking_award | 奖励档位 | activity_id 索引 |
| walking_certificate | 证书 | (member_id, activity_id) 唯一 |
| walking_cheat_log | 作弊处理审计 | member_id/activity_id 索引 |
| walking_audit_log | 报名审核日志 | registration_id 索引 |

## 4. 状态机（报名）

```
0 待提交草稿 →（提交+自动审核）→ 1 待审核 →（通过）→ 2 审核通过（锁定姓名/手机号）
                                    ↑ 未通过退回草稿并提示
管理员：2→3 已取消；2→4 已停用；任意→调整单位
```
> 状态码、流转规则详见《01-需求说明.md》第 4 节。

## 5. 索引设计

| 表 | 索引 | 用途 |

## 6. 关键统计 SQL 口径

- 活动报名数：`SELECT activity_id, COUNT(*) FROM walking_registration WHERE status IN (1,2) GROUP BY activity_id`
- 会员某日步数：`SELECT steps FROM walking_step_record WHERE member_id=? AND activity_id=? AND record_date=?`
- 会员累计积分：`SELECT SUM(points) FROM walking_points WHERE member_id=? AND activity_id=?`
- 活动排行：`SELECT member_id, SUM(steps) total FROM walking_step_record WHERE activity_id=? AND abnormal_flag=0 GROUP BY member_id ORDER BY total DESC`
- 异常数据：`SELECT * FROM walking_step_record WHERE abnormal_flag=1 AND activity_id=?`
