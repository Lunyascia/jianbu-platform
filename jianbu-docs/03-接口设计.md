# 健步走线上活动系统 — 接口设计

- 统一前缀：后端接口均在 `/walking/**`
- 统一返回：`{ code, msg, data }`（RuoYi 规范，code=200 成功；分页 data 含 rows/total）
- 鉴权：
  - 小程序公开接口（登录、活动列表）→ Controller 类加 `@SaIgnore`
  - 小程序登录后接口 → Header `Authorization: <token>`
  - 管理端接口 → `@SaCheckPermission("walking:xxx:xxx")`，需后台登录态
- 微信内容安全：开发期本地敏感词过滤；接入真实 AppID 后切 `security.msgSecCheck`

## A. 小程序端接口

### A1. 会员登录（微信 openid）
`POST /walking/member/login` （匿名）
入参：
```json
{ "xcxCode": "wx.login 得到的 code" }
```
逻辑：code → code2session 换 openid → 查 walking_member
- 已存在 → 生成 token 返回
- 不存在 → 自动创建会员（openid），返回 `needPhone: true` 待绑定手机号
返回：
```json
{ "code":200, "data": {
    "accessToken": "...", "expireIn": 86400,
    "memberId": 1, "needPhone": true, "phone": null
}}
```

### A2. 绑定手机号
`POST /walking/member/phone` （需登录）
入参：`{ "phone": "13800000001" }`
校验：格式、唯一（uk_member_phone）、内容安全
返回：绑定成功 / 已被他人占用 / 含敏感词拒绝

### A3. 活动列表（公开）
`GET /walking/activity/list` （匿名）
参数：`status`（默认 1 进行中）、pageNum、pageSize
返回：活动分页列表

### A4. 活动详情（公开）
`GET /walking/activity/{id}` （匿名）

### A5. 提交报名
`POST /walking/registration/submit` （需登录）
入参：
```json
{
  "activityId": 1001,
  "realName": "张三",
  "phone": "13800000001",
  "idCard": "",          // 可选
  "deptId": 101,
  "deptName": "测试县总工会"
}
```
逻辑：写入/更新 walking_member 基本信息 → 建/更报名记录 → **自动审核**（字段校验 + 手机号唯一 + 敏感词）→
- 通过：status=2，返回成功；锁定姓名/手机号
- 未通过：status=0（退回草稿），`audit_result` 返回修改提示
- 报名时间窗口外 / 非进行中活动 → 拒绝

### A6. 保存报名草稿
`POST /walking/registration/draft` （需登录）
保存为 status=0，可多次修改

### A7. 我的报名状态
`GET /walking/registration/mine` （需登录）
返回：会员当前报名记录 + 状态

### A8. 同步微信步数
`POST /walking/step/sync` （需登录，已报名且审核通过）
入参：
```json
{ "activityId": 1001, "encryptedData": "...", "iv": "...", "recordDate": "2026-08-12" }
```
逻辑：开发期 `encryptedData` 可传模拟步数；真号后解密 getWeRunData 数据 → 计算积分 → 写 walking_step_record + walking_points
返回：`{ "steps": 6000, "points": 60, "abnormalFlag": 0 }`

### A9. 我的今日/累计步数与积分
`GET /walking/step/mine?activityId=1001` （需登录）
返回：今日步数、累计步数、累计积分、达标进度

### A10. 积分排名
`GET /walking/ranking/list?activityId=1001&pageNum=1&pageSize=20` （需登录）
返回：排行列表（名次、姓名、单位、总步数/积分）+ 我的名次

### A11. 奖励介绍
`GET /walking/award/list?activityId=1001` （匿名/登录均可）

### A12. 我的证书
`GET /walking/certificate/mine?activityId=1001` （需登录）
返回：证书信息（名次、编号、图片）

## B. 管理端接口（后台，需权限）

### B1. 活动管理
| 接口 | 权限 | 说明 |
|---|---|---|
| GET /walking/admin/activity/list | walking:activity:list | 分页查询 |
| GET /walking/admin/activity/{id} | walking:activity:query | 详情 |
| POST /walking/admin/activity | walking:activity:add | 新增 |
| PUT /walking/admin/activity | walking:activity:edit | 修改 |
| DELETE /walking/admin/activity/{ids} | walking:activity:remove | 删除 |

### B2. 报名管理
| 接口 | 权限 | 说明 |
|---|---|---|
| GET /walking/admin/registration/list | walking:registration:list | 分页（含会员信息） |
| PUT /walking/admin/registration/cancel | walking:registration:cancel | 取消报名（→3） |
| PUT /walking/admin/registration/disable | walking:registration:disable | 撤下信息+停用账号（→4） |
| PUT /walking/admin/registration/dept | walking:registration:dept | 调整单位 |

### B3. 会员管理
| 接口 | 权限 | 说明 |
|---|---|---|
| GET /walking/admin/member/list | walking:member:list | 分页（按单位/状态/手机号筛选） |
| PUT /walking/admin/member/dept | walking:member:edit | 调整单位 |
| PUT /walking/admin/member/status | walking:member:edit | 启用/停用账号 |

### B4. 数据统计
| 接口 | 权限 | 说明 |
|---|---|---|
| GET /walking/admin/stat/overview | walking:stat:list | 总览：报名数、参与数、总步数 |
| GET /walking/admin/stat/registration | walking:stat:list | 按单位报名统计 |
| GET /walking/admin/stat/ranking | walking:stat:list | 步数/积分排行 |
| GET /walking/admin/stat/step-trend | walking:stat:list | 每日步数趋势 |

### B5. 异常/作弊处理
| 接口 | 权限 | 说明 |
|---|---|---|
| GET /walking/admin/cheat/list | walking:cheat:list | 异常数据分页（abnormal_flag=1） |
| POST /walking/admin/cheat/mark | walking:cheat:handle | 批量标记异常 |
| POST /walking/admin/cheat/delete | walking:cheat:handle | 批量删除异常步数数据（留审计） |
| POST /walking/admin/cheat/disable | walking:cheat:handle | 批量停用作弊账号 |
| GET /walking/admin/cheat/log | walking:cheat:list | 处理记录审计日志 |

## C. 组织机构（复用若依现成接口）

工会组织机构树复用 `sys_dept`，后台"部门管理"现有接口：
- `GET /system/dept/list`、`POST /system/dept`、`PUT /system/dept`、`DELETE /system/dept/{id}`
- 用 `dept_category` 区分工会组织类别
- 会员/报名的"单位"即 sys_dept 的 dept_id

## D. 公共约定

- 分页参数：`pageNum`、`pageSize`，返回 `{ rows, total }`
- 时间参数：`recordDate` 格式 `yyyy-MM-dd`；`registerStart/End` 格式 `yyyy-MM-dd HH:mm:ss`
- 错误码沿用 RuoYi：200 成功 / 500 业务失败（msg 带提示） / 601 警告
