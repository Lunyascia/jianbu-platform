# 微信小程序 AppID 注册指引

> 健步走小程序要真正跑通"微信登录、步数同步、内容安全"，必须有**真实的小程序 AppID**。
> 开发调试阶段可以先用模拟数据，但建议尽早注册（免费、个人主体即可）。

## 一、注册小程序账号

1. 打开微信公众平台：**https://mp.weixin.qq.com**
2. 点击右上角"**立即注册**"
3. 账号类型选择"**小程序**"（不要选订阅号/服务号）
4. 按提示填写：
   - **邮箱**：一个未注册过微信公众平台/小程序/公众号的邮箱
   - 设置密码 → 到邮箱收激活邮件 → 点击激活链接
5. 激活后继续完善资料：
   - **主体类型**：个人（免费）或 企业/工会组织（需营业执照）
   - **管理员信息**：姓名 + 手机号 + 身份证号（扫码确认）
6. 提交后一般**1~7 天内审核通过**（个人主体通常较快）

## 二、获取 AppID 和 AppSecret

注册审核通过后：
1. 登录 mp.weixin.qq.com
2. 左侧菜单 → "**开发管理**" → "**开发设置**"
3. 页面顶部即可看到：
   - **AppID**：形如 `wx1234567890abcdef`
   - **AppSecret**：点击"生成/重置"，用**管理员微信扫码**后显示，复制保存（只显示一次）
4. 记录这两个值 → 填入后端 `application.yml` 的 `wx.appid` / `wx.secret`

> ⚠️ AppSecret 相当于小程序密码，**不要**提交到 git、不要发到公共环境。

## 三、开发调试阶段（拿到 AppID 之前/之后都可用）

| 工具 | 用途 | 获取方式 |
|---|---|---|
| **微信开发者工具** | 本地运行/调试小程序 | 官网下载：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html |
| 测试号（可选） | 快速体验，无真实能力 | mp.weixin.qq.com → 开发设置 → 测试号 |
| 手机 | 真机预览（需真 AppID） | 开发者工具 → 预览 → 微信扫码 |

## 四、开发期用模拟数据的方案（本系统已预留）

在拿到真实 AppID 前，后端已设计为可切换：
- **登录**：`/walking/member/login` 支持传模拟 openid（如 `dev_test_xxx`），直接建会员
- **步数同步**：`/walking/step/sync` 支持传 `steps` 字段直接入库，代替真实微信步数
- **内容安全**：`wx.content-check.enabled=false` 时用本地敏感词过滤
- 拿到真号后：`wx.appid/secret` 填上、`content-check.enabled=true`，前端改用 `uni.login()` 真实 code，即可无缝切换

## 五、正式发布前必做

1. 配置后端 HTTPS 域名 + 微信后台添加"request 合法域名"（见《05-部署文档.md》第 4 节）
2. 后端填真实 `wx.appid/secret`
3. 真机测试步数同步（需授权"微信运动"）
4. 提交审核：HBuilderX → 发行 → 小程序-微信 → 上传 → 公众平台提交审核 → 发布
